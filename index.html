Identity and access

Authentication guidance

Use the authentication pattern that matches the app type you registered in the Trimble Developer Console.

Extension App vs End-User App: Extensions run inside Trimble Connect and use the Workspace API's permission flow for the host-managed access token. Standalone cloud integrations use the configured OAuth flow and service-specific credentials.

Workspace extension

Recommended for in-Connect testing.

  1. Register an Extension App in the Developer Console.
  2. Host this application over HTTPS.
  3. Add the extension manifest URL in the appropriate Trimble Connect project settings.
  4. Connect through TrimbleConnectWorkspace.connect(window.parent, callback).
  5. Request token permission only when required and approved.

Standalone REST integration

For external applications and backend services.

  1. Register the appropriate End-User App or integration.
  2. Configure redirect URI, scopes and OAuth flow.
  3. Keep client secrets on a trusted server.
  4. Use a valid access token for the target service and region.
  5. Check permissions, expiry, status codes and audit logs.
